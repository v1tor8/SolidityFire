# SolidityFire

Watches transaction history and token balances in a user's Ethereum wallet across multiple exchanges in real time.

With SolidityFire, you get a lightweight tool that stays out of your way.

**What you get**

- Watches transaction history and token
- balances in a user's Ethereum

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/SolidityFire.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

SolidityFire is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
